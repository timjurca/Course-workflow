# How this course folder works

Written by the `course-setup` skill. The prose is in the course language; the
folder names, file prefixes and frontmatter keys are fixed English and must not
be translated or re-cased, because scripts match them as literal strings.

## Where to put things during the week

Drop anything into **`_Inbox/`** and ask to file it. You do not have to name the
lesson: the filing step proposes a destination for each file and you approve or
correct the whole batch in one reply. Nothing moves before you approve it.

Files that could be an exam, a set of solutions, an assignment brief or your own
answer sheet are always asked about, never guessed. A past exam misfiled as a
handout becomes a lecture source for the notes and is invisible to the revision
skill, and nothing downstream can detect that.

## The folders

| Folder | What it holds |
|---|---|
| `_Inbox/` | Unfiled material. `_conflicts/` holds iCloud conflicted copies, `_undone/` holds files set aside by an undo. Neither is ever picked up again automatically. |
| `Lessons/NN_YYYY-MM-DD/` | One lecture. `Content/` holds its sources, `Articles/` its assigned papers, `Final_notes/` the generated notes. |
| `Tutorials/NN_YYYY-MM-DD/` | Same shape, for tutorials. |
| `Books/` | Textbooks, plus one `*.index.md` per book. Books never live inside a lesson. |
| `Articles/`, `Videos/`, `Links/` | **Generated** shared notes, one per source, written by the notes skill and shared across lessons. You never put anything here yourself. |
| `Assignments/` | Briefs, your submissions, and any graded feedback. Briefs are read as a signal of what is assessed. **No skill solves an assignment.** |
| `Exams/` | `Past_exams/` and your attempts, `Mock_exams/` and `Revision_questions/` generated by the revision skill. |
| `Explanations/` | Tutor explanations. **Not course material, not examinable, and read by no other skill.** |

## Names

- Lesson and tutorial folders are `NN_YYYY-MM-DD`, zero padded, so they sort in
  date order.
- Files in `Content/` carry a prefix: `slides_`, `transcript_`, `notes_`,
  `handout_`.
- Generated files carry the course code, e.g. `{{code}}_L03_Final_notes.md`.
  Obsidian resolves wiki links by filename across the whole vault, so
  without the code every course's lesson 3 would collide on one name and Obsidian
  would pick one silently.

**Do not rename or translate a folder name.** A renamed `Content/` is invisible
to every later run of every skill.

## Machine-owned, do not edit by hand

- `Weekly_overview.md` frontmatter and tables — ask instead; the skill maintains them
- `Table_of_contents.md` between its generated markers
- `_Inbox/_filing_log.md` — **never edit or clear it.** Undo and lesson
  renumbering both read it, and the other skills migrate their records from it.
- `.data/` and every `.work/` folder
- Everything under `Final_notes/`

## Yours, and protected

These blocks are preserved word for word every time a file is regenerated:

- `## My additions` in the notes and in shared article, video and link notes
- `## My notes` in a lesson overview and in a saved explanation
- `## My questions` in a revision file

Write in them freely. The tutor skill may read them to work out where a
misunderstanding is; nothing ever writes into them.

## Asking for a change

Say what you want in plain language. Anything that moves, renames or overwrites
is shown to you as a plan first, and a one-word correction changes it.
